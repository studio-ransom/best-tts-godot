best-tts

High-quality neural text-to-speech, running entirely inside Godot.

Pure GDScript and GLSL. No C++, no GDExtension, no executables, no server.

GitHub Apache-2.0 Godot 4.4+ Anthracite on Steam

Hear it

Every clip came out of Godot on an RTX 4070 Ti. Same line, different voice pack. Nothing was touched afterwards — no EQ, no compression, no editing.

“Hello from Godot. This is Kokoro speaking.”

am_adam American English, male
af_alloy American English, female
am_onyx American English, male
am_fenrir American English, male
em_alex Spanish pack reading English, for the accent

Five of fifty. The rest ship with the addon.

Use it

Drop in a BestVoicePlayer — an AudioStreamPlayer with text and voice in the inspector — and call it. No engine node, no autoload, no plugin to enable. 

$Voice.speak("I have wares, if you have coin.")

What it costs

Synthesis speed~9× realtime (3.3 s line in ~600 ms, RTX 4070 Ti)
Main thread, per line0.06 ms to queue a full page of text
Cache hit0.16 ms, same frame
VRAM at rest~190 MB
On disk113 MB — model, 50 voices, English lexicons
Per-word costnothing, forever, offline

Why it matters that it is pure GDScript

Every other route to neural speech in Godot drags something with it: a GDExtension you compile per platform, an onnxruntime DLL, a bundled Python, or a cloud endpoint that meters you by the character and can go down. This is a data file and a pile of .gd and .glsl that Godot already knows how to load. It exports like any other project, and your players install nothing.

The honest tradeoff: it needs a Vulkan-capable GPU and the Forward+ or Mobile renderer, because the compute shaders have to run somewhere.
